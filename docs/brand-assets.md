# Brand assets

Instagram, Facebook, TikTok, Threads and X SVG marks are vendored from Simple Icons 16.0.0 (CC0): https://github.com/simple-icons/simple-icons/tree/16.0.0/icons

Shapes are unchanged, displayed in monochrome. Brand names remain as accessible alt text and tooltips. Trademarks belong to their respective owners. The website does not claim affiliation.

The project logo uses stacked media frames, with no directional arrow.
