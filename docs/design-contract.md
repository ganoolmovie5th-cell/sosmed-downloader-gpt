# UI contract

Purpose: paste a public post URL, inspect available media, save selected files.
Language: Indonesian. Target viewports: 390x844 and 1440x1000.
Direction: quiet editorial utility, cream surface, forest green action, restrained ochre accents.
Reference: the product's single-URL workflow dictates one prominent input; results directly below it.
Identity: original SVG arrow entering a tray; matching folder illustration made from CSS, no stock or fake results.
Primary action visible in first viewport; no horizontal overflow at either target width.
Controls have labels, keyboard focus and 44px touch areas. Reduced motion disables spinner.
Loading: stable results area, progress text, cancel. Empty: guidance, no invented media.
Error: specific message, editable URL, retry. Partial: visible warnings above returned files.
Success: file count, per-file download and original URL fallback. Permission: clipboard failure explains manual paste.
Platform availability is derived from live tests; isolated samples never imply universal support.
