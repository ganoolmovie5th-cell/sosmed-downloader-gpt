Sebelum menyimpan

Apakah ini kualitas original?

Kami tidak mengompresi ulang media. “Kualitas tertinggi” berarti varian terbaik yang berhasil ditemukan pada sumber, bukan berkas asli sebelum diunggah ke media sosial. Sebagian sumber memisahkan audio dan video; hasil akan diberi label.

Kenapa ada postingan yang gagal?

Platform dapat meminta login, membatasi akses otomatis, menghapus media, atau mengubah format datanya. Coba postingan publik lain. Aplikasi tidak meminta password atau cookie akun Anda.

Apakah tautan saya disimpan?

Aplikasi tidak menyimpan riwayat URL atau media di database. URL dikirim ke server dan platform sumber untuk diproses. Penyedia hosting dapat mencatat metadata permintaan. Memuat pratinjau dan mengunduh menghubungkan browser Anda ke sumber media.

Apakah gratis?

Aplikasi ini tidak memakai API berbayar. Ketersediaannya tetap mengikuti kuota hosting dan batas akses platform. Unduh konten milik Anda atau yang Anda punya izin untuk simpan.
